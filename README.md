## Cómo usarlos
- **En línea (sin instalar nada):** abra el cuaderno en Google Colab con el botón de cada archivo.
- **En su computador:** instale Python 3.13 y ejecute
  `pip install -r requirements.txt`, luego abra los cuadernos con Jupyter.
